# Hulan Jewelry

Бугуйвч өөрөө зохиох боломжтой Монгол хэлний дэлгүүрийн ажилладаг эхний хувилбар. Next.js App Router, React, TypeScript, native modern CSS, SVG, PostgreSQL / SQLite.

## Локалд ажиллуулах

Node.js 24+ шаардлагатай. Windows PowerShell дээр execution policy-оос хамаарахгүй `npm.cmd` ашиглана.

```powershell
npm.cmd install
npm.cmd run setup
npm.cmd run dev
```

- Нүүр: http://127.0.0.1:3000
- Дизайнер: http://127.0.0.1:3000/design
- Админ: http://127.0.0.1:3000/admin

`setup` нь `.env.local` файлд санамсаргүй `ADMIN_PASSWORD`, `SESSION_SECRET` үүсгэнэ. Админы нууц үгийг уг файлаас харна. Өмнөх тохиргоог дарж бичихгүй. Нууц үг, database, хэрэглэгчийн мэдээлэл Git-д орохгүй.

## Одоо ажиллаж буй боломжууд

- Цайвар ivory / sage / rose / lavender өнгөтэй responsive нүүр, цуглуулга, чулууны танилцуулга.
- 3 хэсэгтэй DIY студио: зүүн талд чулуу/charms каталог, голд угсралтын талбар, баруунд хэмжээ, үнэ, захиалгын товч.
- Интерактив SVG бугуйвч: хоосноос эхлэх, 6 төрлийн чулууг нэр/өнгөөр шүүх, нэг нэгээр нэмэх эсвэл нэг чулуугаар бөглөх, солих, устгах, хулгана/touch-оор чирж байрлалыг солих, товчлуураар зөөх, undo, 3 бэлэн хослол.
- Тусдаа Charms таб: 6 жишиг зайлагч, унжлага, од/нар чимэглэл; төрөл, нэрээр шүүх, чулуутай хольж байрлуулах, нийт үнэ, захиалга, админы үлдэгдэлд тооцох.
- 13–22 см бугуйн хэмжээ, 8 мм чулуу, тооцоолсон дотор тойрог, чулууны тоог тааруулах.
- Нэг загварыг тухайн хөтөчдөө хадгалах, дахин нээх. Захиалгаас дизайнер руу буцахад загвараа үргэлжлүүлэх.
- Хүргэлтийн мэдээлэлтэй захиалга, серверийн үнийн тооцоо, давхар илгээлтийн хамгаалалт.
- Банкны шилжүүлгийн мэдээлэл, давтагдахгүй гүйлгээний код, нууц холбоосоор төлөв харах.
- Админ нэвтрэлт, захиалга хайх/шүүх, банкны гүйлгээний лавлагаатай төлбөр батлах, хүргэлт, дуусгах, цуцлах.
- Материалын үнэ, үлдэгдэл, худалдаанд харагдах эсэхийг өөрчлөх.
- Төлбөр батлах үед нөөц хасах; бэлтгэж буй захиалгыг цуцлахад нөөц буцаах; үйлдлийн түүх хадгалах.

## Төлбөрийн тохиргоо

`.env.local` дотор бодит мэдээллээ оруулна:

```dotenv
BANK_NAME=
BANK_ACCOUNT=
BANK_HOLDER=
```

Эдгээр хоосон үед локал `ALLOW_PREVIEW_ORDERS=true` тохиргоогоор зөвхөн туршилтын захиалга үүсгэнэ. Бодит данс зохиож харуулахгүй. Нийтэд нээхдээ `ALLOW_PREVIEW_ORDERS=false` болгож, банкны мэдээллийг заавал тохируулна. Environment өөрчилсний дараа серверээ дахин асаана.

Төлөв: `pending → preparing → shipped → completed`. `pending` болон `preparing` үед цуцалж болно. Админ мөнгө орсныг өөрөө шалгана. Цуцлалтын мөнгөн буцаалт автомат биш; банкнаасаа хийж тайлбар тэмдэглэнэ.

## Өгөгдлийн хадгалалт

Локалд `DATABASE_URL` хоосон үед `data/hulan.sqlite` ашиглана. PostgreSQL ашиглах бол `.env.local` дотор `DATABASE_URL=postgresql://postgres:<password>@localhost:5432/hulan_jewelry` гэж тохируулаад серверээ дахин асаана. Хүснэгт, жишиг материал анхны холболтоор үүснэ. Тестүүд тусдаа database ашиглана.

Production: `DATABASE_URL`-д PostgreSQL connection string өгнө. `APP_ORIGIN`-д нийтэд харагдах HTTPS origin-оо төгсгөлийн `/`-гүй оруулна. `pg` driver нь connection string-ийн TLS тохиргоог ашигладаг; гэрчилгээний шалгалтыг кодоор унтраагаагүй.

Локал `localhost` PostgreSQL нь Vercel deployment-д харагдахгүй. Vercel-д Neon зэрэг нийтэд холбогдох PostgreSQL баазын `DATABASE_URL`-ийг Project Settings → Environment Variables-д тусад нь тохируулна.

Анхны холболтоор хүснэгт, индекс, туршилтын материалын каталог үүснэ. PostgreSQL advisory lock болон SQLite-ийн serialized transaction нь давхар төлбөр батлах, нөөцийн зэрэгцээ өөрчлөлтийг хамгаална. SQLite → PostgreSQL өгөгдөл автоматаар шилжихгүй; production эхлэхийн өмнө migration, backup/restore болон PostgreSQL дээр интеграцийн шалгалт хийнэ. Энэ орчинд PostgreSQL сервер байгаагүй тул PostgreSQL замыг бодит сервер дээр хараахан шалгаагүй.

## Дизайн ба хөдөлгөөн

Native CSS layers, Grid, `clamp()`, `color-mix()`, `backdrop-filter`, sticky байрлал, hover / focus interaction, `animation-timeline: view()` ашиглав. Нүүр хуудасны шилжилтийн хэлбэр, бүтээгдэхүүний зураг, хэсгүүд доош гүйлгэхэд хоосон зайнаас тэлж гарч ирнэ. Desktop дэлгэцэнд нэг wheel хөдөлгөөн нэг бүтэн хэсэг рүү шилжинэ; mobile болон намхан дэлгэцэнд урт агуулгыг алгасахгүйгээр энгийн гүйлгэлт, зөөлөн snap ажиллана. Scroll animation дэмжихгүй хөтөчид агуулга хэвийн харагдана. `prefers-reduced-motion` тохиргоотой үед хөдөлгөөн унтарна. Доош сумыг дарахад цуглуулга руу зөөлөн гүйлгэнэ.

Browser-ийн scrollbar-ыг харагдахгүй болгосон ч mouse, trackpad, touch болон keyboard гүйлгэлт хэвийн ажиллана. Scroll morph нь layout/blur animation ашиглахгүй, compositor-д хөнгөн `transform` ба `opacity`-гоор хөдөлнө.

Чулууны дүрслэл нь кодоор үүсгэсэн загварчилсан SVG; бодит бүтээгдэхүүний зураг биш. Google Fonts сүлжээгүй үед системийн serif / sans-serif fallback ажиллана.

SVG чулуу бүр олон үеийн radial gradient, чиглэсэн гэрлийн ойролт, ирмэгийн гялбаа, тусдаа зөөлөн сүүдэртэй. Дизайнерын эд ангийг хулгана эсвэл touch-оор нөгөө эд анги дээр чирэхэд хоёр байрлал солигдож, undo болон хадгалалтдаа тэр дараалал очно.

## Дараагийн үе шат

Дэлгэрэнгүй дараалал [PLAN.md](./PLAN.md)-д бий. Одоогийн хувилбар нь локалд турших суурь:

- Каталогийн нэр, үнэ, 12,000 ₮ урлал / 6,000 ₮ хүргэлт, 500 ширхэг анхны үлдэгдэл нь жишиг өгөгдөл. Бодит каталогоор солино.
- Нөөц одоогоор төлбөр батлах үед хасагдана. Төлбөр хүлээж буй захиалга нөөц эзэмшихгүй. Нийтэд нээхийн өмнө хугацаатай нөөц хадгалах, төлбөрийн хугацаа, хүрэлцээгүй нөөцтэй шилжүүлгийг шийдвэрлэх бодлого нэмнэ.
- Дотор тойргийн тооцоог бодит материал, уяа, сул зайтай харьцуулж үйлдвэрлэлийн хэмжилтээр тохируулна.
- Админ нэг эрхтэй; shared password, 8 цагийн session, database-д 15 минутад 10 login оролдлогын хязгаартай. Олон ажилтны эрх, 2FA, session revoke, сэргээх процесс нэмэх шаардлагатай.
- Захиалгын жагсаалт сүүлийн 200 бичлэгтэй. Pagination, экспорт, олон админы inventory conflict handling, audit viewer дараагийн шатанд.
- Бүтээгдэхүүн/зураг шинээр нэмэх админ CMS, үнийн audit, мэдэгдэл, account, cloud saved designs, public community gallery хараахан хийгдээгүй.
- Одоогийн каталог 8 мм зургаан төрлийн чулуу, зургаан SVG жишиг charm-тай. Charm бүр үнэ, үлдэгдэлтэй; угсралтын хэмжээний тооцоонд нэг 8 мм оролт гэж тооцно. Бодит charm-ийн хэмжээ, материал, зураг болон 6/10 мм чулууг үйлдвэрлэлийн мэдээллээр өргөтгөнө.
- Production rate limiting / anti-spam, privacy/returns/contact, HTTPS, мониторинг, backup, accessibility review хийнэ.
- Одоогоор deploy хийгдээгүй.
